# Ortalama Hesaplama

Terminalde çalışan, 2 sayının ortalamasını hesaplayan basit bir Python programı.

## Kullanım

```bash
python ortalama_hesaplama.py
```

## Örnek Çıktı

```
=== Ortalama Hesaplama (2 Sayi) ===

  1. Sayi: 10
  2. Sayi: 20

Girilen sayilar : 10.0 ve 20.0
Ortalama        : 15.0000
```
